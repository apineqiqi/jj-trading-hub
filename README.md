# JJ 交易中枢

个人交易中枢 V1.0。目标不是通用行情 App，而是服务 JJ 及不同账户用户的真实持仓、关注池、交易规则和每日决策。

## V1.0 风险预算与仓位工作台

- 按用户独立设置单股仓位、组合仓位、单笔风险和单日亏损上限
- 根据账户净资产、入场价和止损价计算单笔风险可承受股数
- 叠加单股与组合仓位余量后，按 A 股 100 股一手向下取整
- 同步展示占用资金、计划最大亏损、计划盈亏比与计划后仓位
- 支持保存和删除交易计划；所有参数仍只保存在当前浏览器，不会自动下单

## V0.9 盘面证据库

- 按用户和观察标的保存分时图、K 线或账户盘面截图
- 记录盘前、盘中、收盘阶段以及事实、判断和下一步触发/失效条件
- 图片压缩后仅保存在当前浏览器，并跟随隐私模式遮挡
- 自动整理可复制的 AI 分析简报，明确区分已确认事实与主观判断
- 本阶段不自动上传图片，也不伪装成已经完成云端 AI 看图

## V0.8 条件提醒

- 从观察池触发位与失效位自动生成初始价格提醒
- 支持按用户新增、暂停、恢复、确认和删除提醒
- 行情刷新后自动判断上穿与下破条件，并在页头显示命中数量
- 可由用户主动开启浏览器系统通知，未授权时仍保留页面内提醒
- 明确说明页面关闭后不会后台监控，避免把本地能力误解为全天候推送

## V0.7 交易日工作流

- 新增盘前、盘中、收盘三阶段交易日驾驶舱
- 每个阶段提供可执行检查清单、进度反馈与独立备注
- 按日期和用户分别保存流程记录，刷新页面不会丢失
- 风险仪表同步展示当前仓位、持仓数量与转强信号
- 隐私模式同步遮盖工作流中的敏感持仓信息

## V0.6 第一阶段

- 独立用户档案，可创建、改名、归档和恢复
- 顶部一键切换“全账户 / 单用户”视角
- 持仓、观察池和总览统计随用户自动隔离
- V0.5.1 的行情刷新、账户快照、交易复盘和隐私模式完整保留
- V0.2–V0.5.1 本机数据无损迁移到 V0.6 用户账户

## V0.5.1 小更新

- 隐私选择保存在当前浏览器，刷新页面后保持不变
- 隐藏状态覆盖总资产、现金、仓位、持仓标的、数量、成本、市值、盈亏与复盘金额

## 核心原则
事实口径未确认时，只给条件判断；任何新增仓位都必须具备触发价、失效价和仓位动作。

## GitHub Pages 部署

本仓库已内置 `.github/workflows/deploy-pages.yml`。把代码推送到 GitHub 的 `main` 分支后：

1. 打开仓库 **Settings → Pages**。
2. 在 **Build and deployment → Source** 中选择 **GitHub Actions**。
3. 打开 **Actions** 查看 `Deploy JJ Trading Hub to GitHub Pages` 工作流。
4. 部署完成后，Pages 页面会显示可访问网址。

Vite 已使用相对资源路径，因此既支持 `用户名.github.io/仓库名/`，也方便后续绑定自定义域名。
