# JJ 交易中枢

个人交易中枢 V0.7。目标不是通用行情 App，而是服务 JJ 及不同账户用户的真实持仓、关注池、交易规则和每日决策。

## V0.7 交易日工作流

- 新增盘前、盘中、收盘三阶段交易日驾驶舱
- 每个阶段提供可执行检查清单、进度反馈与独立备注
- 按日期和用户分别保存流程记录，刷新页面不会丢失
- 风险仪表同步展示当前仓位、持仓数量与转强信号
- 隐私模式同步遮盖工作流中的敏感持仓信息

## V0.6 第一阶段

- 独立用户档案，可创建、改名、归档和恢复
- 顶部一键切换“全账户 / 单用户”视角
- 持仓、观察池和总览统计随用户自动隔离
- V0.5.1 的行情刷新、账户快照、交易复盘和隐私模式完整保留
- V0.2–V0.5.1 本机数据无损迁移到 V0.6 用户账户
- 用户归档不删除任何持仓或观察池数据

## V0.5.1 小更新

- 新增持仓隐私模式，可一键隐藏或显示账户与持仓敏感信息
- 隐私选择保存在当前浏览器，刷新页面后保持不变
- 隐藏状态覆盖总资产、现金、仓位、持仓标的、数量、成本、市值、盈亏与复盘金额

## V0.5 当前版本

- 接入公开延迟行情，自动同步持仓与观察池中的 6 位 A 股代码
- 首次打开自动刷新，页面保持打开时每 60 秒刷新一次，也可随时手动刷新
- 明确展示行情状态、数据时间与来源，刷新失败不会覆盖已有价格
- 行情刷新后按最新价重新估算持仓市值、浮盈亏和总资产
- 每个已更新标的展示“行情”标记，便于区分券商截图值与行情估算值

## 核心原则
事实口径未确认时，只给条件判断；任何新增仓位都必须具备触发价、失效价和仓位动作。

## GitHub Pages 部署

本仓库已内置 `.github/workflows/deploy-pages.yml`。把代码推送到 GitHub 的 `main` 分支后：

1. 打开仓库 **Settings → Pages**。
2. 在 **Build and deployment → Source** 中选择 **GitHub Actions**。
3. 打开 **Actions** 查看 `Deploy JJ Trading Hub to GitHub Pages` 工作流。
4. 部署完成后，Pages 页面会显示可访问网址。

Vite 已使用相对资源路径，因此既支持 `用户名.github.io/仓库名/`，也方便后续绑定自定义域名。
