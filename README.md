# JJ 交易中枢

个人交易中枢 V0.3。目标不是通用行情 App，而是服务 JJ 自己的真实持仓、关注池、交易规则和每日决策。

## V0.3 当前版本

- 已同步 JJ 在 2026-09-03 的两笔最新持仓与账户快照
- 总览展示总资产、持仓市值、可用现金、浮动盈亏与当前仓位
- 导入持仓按券商截图口径展示市值、浮盈与收益率，避免显示成本价四舍五入带来的误差

## V0.2

- 可按用户标记和筛选的持仓台账，自动计算市值与浮动盈亏
- 可新增、编辑、删除的核心观察池
- 持仓和观察池数据保存在当前浏览器的 localStorage
- 总览 / 持仓 / 观察池三工作区切换
- 响应式手机端布局

## 启动
```bash
npm install
npm run dev
```

## 核心原则
事实口径未确认时，只给条件判断；任何新增仓位都必须具备触发价、失效价和仓位动作。

## GitHub Pages 部署

本仓库已内置 `.github/workflows/deploy-pages.yml`。把代码推送到 GitHub 的 `main` 分支后：

1. 打开仓库 **Settings → Pages**。
2. 在 **Build and deployment → Source** 中选择 **GitHub Actions**。
3. 打开 **Actions** 查看 `Deploy JJ Trading Hub to GitHub Pages` 工作流。
4. 部署完成后，Pages 页面会显示可访问网址。

Vite 已使用相对资源路径，因此既支持 `用户名.github.io/仓库名/`，也方便后续绑定自定义域名。
